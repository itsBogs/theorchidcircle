Orchidcircle - Booking & Profile Management System

Setup:
1. Create a MySQL database (e.g., `orchidcircle`).
2. Update DB credentials in `db.php`.
3. Run `http://yourhost/Orchidcircle/setup.php` once to create tables and default admin.
4. Login at `admin/login.php` (default username `admin`, password `ChangeMe123!`) and change it.

Notes: Designed for shared hosting (cPanel). PHP 7.4+ recommended.
